SRE Multi-Agent Kubernetes Lab & Observability Guide

GK
Govind K (SRE Lead)
Updated Aug 12, 2026 ⏱️ 5 min read APPROVED
ℹ️
System Status Notice: All core services (PostgreSQL, Kafka, Prometheus, Grafana, Java App) are fully containerized and verified healthy.

1. System Overview

This repository provisions a 3-node local Kubernetes cluster on Docker Desktop using kind. It includes an end-to-end SRE observability stack (Prometheus & Grafana via kube-prometheus-stack), Kafka event streaming with ZooKeeper, PostgreSQL relational storage, and a Spring Boot Java web application.

2. Architecture & Components

Component Technology Storage / Replica State Port / Endpoint
Java App Spring Boot 3 + Java 21 Stateless (Replicas: 1) http://127.0.0.1:8080/
PostgreSQL Postgres 16.4 PersistentVolume (2Gi PVC) 5432 / TCP
Kafka & ZooKeeper Bitnami Kafka 3.9 PersistentVolume (5Gi PVC) 9092 / TCP
Prometheus Prometheus Operator ServiceMonitor Scrapes http://127.0.0.1:9090/
Grafana kube-prometheus-stack Dashboards as Code (ConfigMaps) http://127.0.0.1:3000/

3. Single-Command Bootstrap

Run the single bootstrap script to provision the cluster, deploy all workloads, start background port forwarding, and verify local endpoints:

./scripts/bootstrap.sh
⚠️
Resource Requirement: Ensure Docker Desktop is allocated at least 6 GB RAM and 4 CPU Cores under Settings -> Resources.

4. SharePoint List & Grafana Infinity Integration

The lab contains a mock SharePoint OData endpoint at /api/sharepoint/items. Grafana's Infinity Data Source (uid: infinity) fetches this REST endpoint and populates a color-coded Grafana Table panel automatically.
